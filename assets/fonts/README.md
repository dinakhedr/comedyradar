# Fonts for generated images

TTF files for `next/og` (Satori cannot read woff2). Used only on the server by
the Social images route; the website itself loads its fonts with `next/font`.

- `LuckiestGuy-Regular.ttf`: Luckiest Guy 400, from Google Fonts (Apache License 2.0)
- `Nunito-Bold.ttf`, `Nunito-ExtraBold.ttf`: Nunito 700 and 800, from Google Fonts (SIL Open Font License 1.1)
