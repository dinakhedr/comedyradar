# Comedy Radar — logo and icon files

Put the whole `brand` folder in the repository at `public/brand/`.

## Logos (wordmark converted to outlines — no font needed)
| File | Use |
|---|---|
| Logos/comedy-radar-horizontal-dark.svg | Primary logo: website header and footer on purple, banners, screens (includes the Radar Purple background) |
| Logos/comedy-radar-horizontal-light.svg | On white or lavender (transparent background) |
| Logos/comedy-radar-vertical-dark.svg | Square spaces on purple: Instagram posts, posters |
| Logos/comedy-radar-vertical-light.svg | Square spaces on white |

Clear space: the width of the microphone body on every side. Minimum width: 140px (horizontal), 96px (vertical). The full logo never sits inside the yellow square.

## Icons
| File | Use |
|---|---|
| Icons/comedy-radar-app-icon.svg | The icon whenever it appears alone: favicon, app icon, Instagram profile picture |
| Icons/comedy-radar-app-icon-on-dark.svg / -on-light.svg | App icon placed on a purple or white square, for decks and banners |
| Icons/comedy-radar-mark-dark.svg | Free-standing mark on purple: stickers, watermarks, video corners |
| Icons/comedy-radar-mark-light.svg | Free-standing mark on white (transparent background) |

## Web (ready for the Next.js app)
| File | Where it goes |
|---|---|
| Web/favicon.svg | `app/icon.svg` |
| Web/favicon.ico | `app/favicon.ico` |
| Web/apple-touch-icon.png (180×180) | `app/apple-icon.png` |
| Web/icon-192.png, Web/icon-512.png | `public/` — referenced in `site.webmanifest` |
| Web/site.webmanifest | `public/site.webmanifest` |
| Web/logo-horizontal-dark.png | Emails and places that cannot show SVG |
